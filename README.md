# 🍕 Sistema de Pizzaria em Python

Este programa simula pedidos de uma pequena pizzaria. Usei dicionários para guardar o cardápio e os itens anotados no pedido.

## 📚 Conceitos praticados

- **Dictionaries (dicionários):** iteração de dicionários e busca de chaves e valores.
- **Validações:** Uso da palavra chave `continue` em validações de forma a evitar Nested Loops muito grandes.
- **Boas Práticas:** `if __name__ == '__main__'` foi incluído.

## 🚀 Como executar

1. Certifique-se de ter o Python instalado.
2. Clone este repositório:
   ```bash
   git clone https://github.com/Davi-SantosOlv/pizzaria-python.git
   ```
3. Entre na pasta do projeto e execute:
   ```bash
   python main.py
   ```

## 🎯 Objetivo

Me familiarizar com a busca de chaves e valores dentro de dicionários, estruturas de dados umas dentro das outras e iniciar boas práticas de código.
